# Past_Finders
An interactive exploration game uncovering the stories of abandoned lunar and Martian mission equipments, celebrating the discoveries and legacies that continue to inspire future space exploration. 
Every abandoned object has a story. Every mission leaves a legacy.
About the Project
Abandoned, But Not Forgotten is an interactive storytelling game developed for the NASA International Space Apps Challenge 2026.
Players explore extraterrestrial environments, discover abandoned equipment and unlock stories associated with historical space missions.
Featured missions- Phoenix Mars Lander, Surveyor 3
